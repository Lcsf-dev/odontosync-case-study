## 📚 Responsabilidade de cada área

| Área | Finalidade |
| --- | --- |
| README | Apresentação do produto, uso atual, stack e pontos de avaliação técnica. |
| Documentação | Arquitetura conceitual, funcionalidades, fluxos, decisões e aspectos de operação. |
| Captura de tela | Referência visual da interface em um ambiente de teste. |

## 🖼️ Imagem publicada

A captura mostra o painel de um consultório de teste. Os cartões estão sem registros de pacientes, e a imagem não apresenta a operação do consultório real.

Novas imagens devem seguir o mesmo critério: utilizar dados demonstrativos e revisar informações visíveis antes da publicação.

## 🔎 Relação com o produto

O produto principal possui interface, serviços, persistência e rotinas de validação. Este repositório descreve essas responsabilidades e suas decisões sem distribuir uma cópia executável.

O histórico público começa com a documentação e a imagem demonstrativa. Ele não reutiliza commits do repositório privado.
